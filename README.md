# EnchantPickaxe

Плагин для Paper 1.21.4 с кастомными зачарованиями для кирки.

## Зачарования

- **Магнит** — притягивает все добытые блоки прямо в инвентарь
- **Бур** — добывает область 3x3 в зависимости от стороны, куда смотрит игрок
- **Огромный бур** — работает как VeinMiner, добывает всю жилу руды (до 64 блоков)

## Команды

```
/enchantpickaxe <magnet|drill|megadrill>
```

Требуется право `enchantpickaxe.admin` (по умолчанию OP).

## Сборка

```bash
mvn clean package
```

Готовый JAR будет в `target/EnchantPickaxe-1.0.0.jar`.

## GitHub Actions

При пуше в `main`/`master` автоматически собирается артефакт.
